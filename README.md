# 📦 Sistema de Gestão de Estoque

Aplicação web desenvolvida para gerenciamento de produtos, controle de estoque e registro de vendas em tempo real.

## 🚀 Tecnologias Utilizadas
* **Java 17+**
* **Spring Boot** (Spring MVC, Spring Data JPA)
* **Thymeleaf** (Template Engine)
* **Bootstrap 5** (Interface responsiva)
* **H2 Database / MySQL** (Banco de dados)

## 🎯 Funcionalidades
* Cadastrar e editar produtos com validação de formulário
* Listar e buscar produtos por nome
* Registrar vendas com atualização automática de quantidade
* Excluir produtos do sistema
